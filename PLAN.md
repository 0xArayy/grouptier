### R1 — Starting screen retry button
- **Priority:** P1 (UX fix — prior audit item, confirmed still open)

### R2 — api/client.ts fetch helper
- **Priority:** P2 (code quality, DRY)
- **Effort:** CC ~30 min / human: 0 min
- **Files:** `frontend/src/api/client.ts`
- **Problem:** 15 async functions each manually repeat `{ 'x-init-data': getInitData() }` header (sometimes also `'Content-Type': 'application/json'`). One function (`recordTemplateUse`) also skips the `throwOnError` pattern entirely for different reasons.
- **Fix:**
  ```ts
  async function apiFetch(url: string, opts: RequestInit & { json?: unknown } = {}): Promise<Response> {
    const { json, headers: extraHeaders, ...rest } = opts;
    const h: Record<string, string> = { 'x-init-data': getInitData() };
    if (json !== undefined) h['Content-Type'] = 'application/json';
    return fetch(url, {
      ...rest,
      headers: { ...h, ...(extraHeaders as Record<string, string> ?? {}) },
      ...(json !== undefined && { body: JSON.stringify(json) }),
    });
  }
  ```
  Refactor all 15 functions to use `apiFetch`. `recordTemplateUse` keeps its try/catch wrapper (best-effort, never throws). `fetchTemplates` keeps its `signal` passthrough via `opts`.
- **Test:** Existing unit tests for App behavior + manual smoke — fetch calls should still include `x-init-data`

### R3 — Bulk INSERT for public poll options
- **Priority:** P2 (server performance)
- **Effort:** CC ~20 min / human: 0 min
- **Files:** `server/src/routes/publicPolls.ts:83-92`
- **Problem:** `POST /api/public-polls/:id/use` inserts options one-by-one in a for-loop:
  ```ts
  for (const text of options as string[]) {
    await client.query('INSERT INTO options ...', [outcome.id, text]);
  }
  ```
  At 8–32 options this is 8–32 sequential round trips inside a transaction.
- **Fix:** Single bulk INSERT with parameterized VALUES:
  ```ts
  if ((options as string[]).length > 0) {
    const vals = (options as string[]);
    const placeholders = vals.map((_, i) => `($1, $${i + 2})`).join(', ');
    await client.query(
      `INSERT INTO options (session_id, text) VALUES ${placeholders}`,
      [outcome.id, ...vals],
    );
  }
  ```
- **Test:** Add test to `publicPolls.test.ts`: `POST /api/public-polls/:id/use` creates session with all N options in the DB
